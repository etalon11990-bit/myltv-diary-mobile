# Источники пресета «Реальная клавиатура»

Проверено 17.11.2026. В комплекте 39 разных WAV: 32 обычных клавиши, 3 пробела, 1 Enter и 3 Backspace. Это обработанные фрагменты физических записей. Генераторы щелчков, изменение высоты тона и непрерывная запись печати в готовом миксе не используются.

| Группа | Автор и источник | Право использования |
|---|---|---|
| 32 обычные клавиши | unicaegames, [Keyboard Soundpack #1](https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes). Cherry KC 1000, микрофон Shure SM7B. Использованы только `Single Keys/keypress-001.wav` … `keypress-032.wav`. | CC0 1.0 на странице автора. Исходный readme сохранён. |
| 3 пробела | JanZavadil, [Sound of spacebar](https://freesound.org/people/JanZavadil/sounds/796112/). Записанный пробел клавиатуры iPad; взяты первые три раздельных удара. | CC0 1.0 на странице звука. |
| Enter | uEffects, [enter key](https://freesound.org/people/uEffects/sounds/180966/). Автор указывает запись клавиш для рекламного ролика. | CC0 1.0 на странице звука. |
| 3 Backspace | qubodup, [Typing And Deleting Keyboard Strokes](https://freesound.org/people/qubodup/sounds/873836/). Logitech Ergo K860, Zoom H2n. Взяты короткие удары из поздней серии удаления; назначение определено по описанной автором последовательности «набор, затем удаление» и регулярной серии в конце записи. | CC0 1.0 на странице конкретного звука. |

[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) допускает копирование, изменение и коммерческое использование. Дополнительная оплата или обязательная атрибуция для этих записей не заявлены. Имена и ссылки сохранены в знак признательности авторам и для проверки происхождения.

Папка `../real_keyboard_sources/` содержит оригинальный архив, скачанные публичные HQ MP3-превью специальных клавиш, SHA-256, оригинальный readme и локальные HTML-копии страниц с CC0. Файлы архива `Generated Typing` не используются в пресете. Второй проверенный вариант Enter оказался копией того же нажатия и в итоговый набор не включён. В браузере были рассмотрены и другие наборы, они в комплект не включены.

Обработка: декодирование в моно 48 кГц, фильтры высоких частот от 65 Гц и низких до 3200 Гц, обрезка ведущей тишины, выравнивание уровня с ограничением пика 0,7, короткие плавные края. Исходные материалы не изменены. Источник и начальный таймкод каждого фрагмента указаны в `pack.json`, каждый итоговый WAV защищён SHA-256.

Во время воспроизведения используется исходная скорость WAV 48 кГц. Для обычных нажатий применяется перемешиваемая очередь всех 32 записей без повторения до исчерпания очереди и без немедленного повтора на границе очередей. Для пробела и Backspace работают отдельные очереди. У Enter одна подтверждённая запись; меняется только её уровень. Дополнительные варианты Enter можно получить импортом собственной записи. Выбор определяется seed проекта, поэтому повторный экспорт воспроизводим.

В готовом дневнике Backspace не вставляется случайно: текст выводится без искусственных ошибок и удалений. Его запись доступна в наборе и отдельной кнопке прослушивания специальных клавиш. Время каждого реального звукового события остаётся привязано к событию текста.
