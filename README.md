# MYLTV Diary Mobile v0.3.0

Локальная студия видеодневника для iPhone: текст, видео, музыка, композиция 55/45.

Откройте сайт GitHub Pages этого репозитория в Safari. Поделиться → На экран Домой → Добавить. Запустите из иконки и дождитесь «Кэш офлайн готов». Затем импортируйте медиа, сохраните запись и сделайте резервную копию .myltv в «Файлы».

Для проверки выключите ПК, включите авиарежим и отключите Wi-Fi, закройте и повторно откройте приложение. Убедитесь, что запись и медиа доступны. Экспорт → Предпросмотр 15 секунд → Тест MP4. При успехе отдельно сохраните MP4 и JSON-отчёт в «Файлы».

**Прототип: MP4 на реальном iPhone 13 пока не подтверждён.** Требуются физические проверки конкретной iOS. Нативная запись не гарантирует строгие постоянные 30 FPS. WebM/MOV и серверный рендер не подставляются.

Проекты и исходники хранятся в IndexedDB устройства. Ничего из них не отправляется на GitHub или сервер обработки. Система может очистить браузерное хранилище: используйте полную резервную копию. Искусственных ограничений видео/музыки 80/24 МиБ и 10/5 минут больше нет. Текст до 100000 UTF-16 единиц; резервная копия ZIP32 менее 4 ГБ. Есть тест записи 15/30/60/90/120 секунд и запись целого дневника. Возможности зависят от ресурсов устройства. Клавиатура: 39 лицензированных CC0 WAV; мягкая/тихая обработка реальных записей отличается от синтетических пресетов Windows. Три режима детерминированного дыма и тления перенесены из Windows.

Обновление установленной PWA без очистки проектов: сначала «Записи → Резервная копия», сохраните .myltv в Файлы. При включённом интернете откройте приложение с прежней иконки, в «Записи» нажмите «Установить обновление», если кнопка появилась. При необходимости закройте приложение и откройте снова. Дождитесь «Кэш офлайн готов»; в диагностике Экспорта должна быть appVersion 0.3.0 и раздел «Клавиши». Не удаляйте PWA и не очищайте данные Safari. Идентификатор, адрес, область Service Worker и база IndexedDB сохранены. Открытие отдельной вкладки Safari не следует использовать вместо проверки проектов в ранее установленной PWA.
